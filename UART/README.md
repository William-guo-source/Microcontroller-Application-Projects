# 💣 UART 雙人對戰拆炸彈 (UART Battleship Game)

這是一個基於 8051 (AT89S52) 微控制器與 C 語言開發的雙人互動遊戲。透過 UART 串列通訊協定，兩台 8051 能夠互相傳遞座標數據與遊戲狀態，實現宛如「踩地雷 / 海戰棋」的連線對戰體驗。

## ✨ 核心功能 (Features)

*   **UART 實體連線對戰：** 使用 Timer 1 模式 2 (Auto-reload) 產生 9600 bps 的 Baud Rate 進行雙向通訊[cite: 4]。
*   **矩陣鍵盤座標輸入：** 支援 4x4 矩陣鍵盤輸入兩位數座標 (00~77)[cite: 4]。具備清除功能 (按鍵值 15)，並可透過特定按鍵 (按鍵值 14) 將座標封包傳送給對手[cite: 4]。
*   **LCD 即時戰況顯示：** 接收對方座標或狀態碼後，LCD 會顯示對應的 `HIT` (命中)、`MISS` (未擊中) 或 `WIN` (勝利) 狀態[cite: 4]。
*   **內建陣列比對演算法：** 預先寫入炸彈座標陣列 (`boom[]`)[cite: 4]。接收對手座標後，系統會自動進行陣列比對，並回傳命中狀態給對方[cite: 4]。

## 🔌 硬體腳位配置 (Hardware Pinout)

本專案的 I/O 腳位定義如下：

| 元件 / 功能 | 8051 腳位 | 說明 |
| :--- | :--- | :--- |
| **UART 傳輸** | `RXD(P3.0)`, `TXD(P3.1)` | 雙機交叉連接 (TX接RX，RX接TX，並共地) |
| **LCD Data Bus** | `P2` | 傳輸 LCD 的 8-bit 字元資料[cite: 4]。 |
| **LCD 控制線** | `P1.0 - P1.2` | 控制 RS (暫存器選擇), RW (讀寫控制), E (致能) 等腳位[cite: 4]。 |
| **矩陣鍵盤** | `P0` | 4x4 矩陣鍵盤掃描線[cite: 4]。 |
